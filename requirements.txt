# Runtime deps layered onto the official apache/airflow image (see Dockerfile).
# apache-airflow itself is deliberately NOT pinned here — it already ships in the base
# image, and repinning it here would fight Airflow's own dependency constraints.
#
# No apache-airflow-providers-mysql/postgres: those pull in mysqlclient (a C
# extension needing system MySQL headers to build) and drag pip's resolver through
# Airflow's entire flask/connexion dependency graph. We only need Airflow's core
# BaseHook.get_connection() to read connection credentials — plain DB clients
# (mysql-connector-python, psycopg2-binary) handle the actual queries.
#
# Left unpinned deliberately: the Dockerfile installs against Airflow's official
# constraints file, which already pins compatible versions of anything it manages —
# a competing hard pin here causes a ResolutionImpossible error.
pandas
mysql-connector-python
psycopg2-binary
python-dotenv
matplotlib
